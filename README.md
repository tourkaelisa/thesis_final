# E-shop (Διπλωματική) — Οδηγίες εκτέλεσης με Docker

Όλη η εφαρμογή (Angular frontend + FastAPI backend + GraphDB triplestore)
σηκώνεται με **μία εντολή**. Χρειάζεται να εγκαταστήσετε μόνο το Docker.

## Προαπαιτούμενα

- **Docker Desktop** (Windows/Mac) ή Docker Engine + Compose (Linux)
  → https://www.docker.com/products/docker-desktop/

## Βήμα 1: Εκκίνηση της εφαρμογής
Ανοίξτε το τερματικό σας μέσα στον φάκελο του project και τρέξτε την παρακάτω εντολή

```bash
docker compose up --build -d
```

## Βήμα 2: Γέμισμα της Βάσης Δεδομένων
Για να μπορέσετε να δείτε τα στατιστικά του e-shop, πρέπει να γεμίσουμε τη βάση. Τρέξτε στο τερματικό την παρακάτω εντολή η οποία θα δημιουργήσει αυτόματα 200 εικονικούς χρήστες και τα αγαπημένα τους προϊόντα:

```bash
docker compose exec backend python seed_data.py
```

## Βήμα 3: Πρόσβαση στο eshop
Ανοίξτε τον browser σας στη διεύθυνση:
**http://localhost:4200**

Για να έχετε δικαιώματα **Αdmin**, θα πρέπει να πάτε στη σελίδα **Εγγραφή** και να φτιάξετε έναν νέο λογαριασμό χρησιμοποιώντας **υποχρεωτικά** το παρακάτω email:
- **Email:** `elisatourka@gmail.com`
- **Κωδικός:** *(εισάγετε όποιον κωδικό επιθυμείτε)*
Επειδή το σύστημα έχει οριστεί να αναγνωρίζει το συγκεκριμένο email, μόλις ολοκληρώσετε την εγγραφή θα σας κάνει αυτόματα ανάθεση στο ρόλο του Διαχειριστή.

Για το GraphDB, ανοίξτε: 
**http://localhost:7200**

## Τερματισμός

```bash
docker compose down
```

Τα δεδομένα της GraphDB διατηρούνται (Docker volume). Για να σβηστούν εντελώς
και να ξαναστηθεί η βάση από την αρχή:

```bash
docker compose down -v
```
